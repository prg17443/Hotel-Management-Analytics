# 🏨 Hotel Management & Analytics System

A Python-based Hotel Management and Analytics project that combines a Streamlit web application, Mysql Database,SQL analysis and PowerBI dashboards.
The system is designed to allow hotel staff to register and manage customer information in a MySQL database, perform SQL-based analysis, and generate business insights using Power BI.
---
## 📌 Project Overview
The main objective of this project is to develop an end-to-end hotel management and analytics solution using Python, Streamlit, MySQL, SQL and Power BI.

The project connects a web-based application with a relational database and an analytics layer to transform hotel data into useful business insights.

The project follows this workflow:

'''text
Hotel Staff
    ↓

    ↓
MySQL Database
    ↓

    ↓
Power BI
    ↓
Business Insights

## 🎯 Objectives
The key objectives of this project are :

- Build a user-friendly hotel management application using streamlit.
- Capture customer information through a web interface.
- Store customer and hotel-related data securely in MySQL database.
- Perform SQL-based data analysis.
- Create meaningful business insights from hotel data.
- Build Power BI dashboards for visualization.
- Develop an end-to-end data analytics project suitable for a portfolio.

## 🖥️ Application Features

The current application includes:

- Customer registration through a Streamlit web interface.
- Input validation for customer details.
- Connection between the Streamlit application and MySQL database.
- Automatic storage of customer information in the database.
- Hotel logo and professional user interface elements.
